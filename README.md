# SomaFM · генератор плейлиста

**soma.guilliman.ru** — генератор актуального M3U8-плейлиста: все радиостанции [SomaFM](https://somafm.com) и десятки тысяч станций со всего мира из открытого каталога [radio-browser.info](https://www.radio-browser.info). Прямо в браузере, без сборки, без бэкенда, без зависимостей: открыл страницу — получил свежий плейлист с прямыми ссылками на потоки.

## Возможности

- **Два источника в одном интерфейсе**: 46 станций SomaFM и мировой каталог radio-browser.info (~60 000 станций). Переключатель источника — сегментный контрол под заголовком.
- **SomaFM**: актуальные логотипы и текущие треки (данные тянутся на лету из открытого API), **три качества потока** — MP3 128, AAC ~130, AAC+ 64.
- **radio-browser.info**: поиск по названию, фильтры по жанру (тегу) и стране, сортировка по голосам/названию, охват топ-30/60/100/200. Показываются только станции, прошедшие последнюю проверку доступности (`hidebroken`).
- **Настраиваемый адрес API**: если официальный `radio-browser.info` недоступен из вашей сети (например, в России он блокируется), укажите свой прокси или зеркало — в поле настроек или параметром `?rb=…`. Работает автоматический фолбэк между адресами.
- **Прямые ссылки на потоки** — SomaFM-ссылки `.pls` резолвятся в реальные URL; у radio-browser берётся уже разрешённый `url_resolved`, чтобы плейлист играл без промежуточных перенаправлений.
- **Плейлист в формате M3U8** из текущего видимого списка (с учётом источника, фильтров и сортировки): скачивание файла (`SomaFM.m3u8` / `Radio.m3u8`) или копирование в буфер обмена.
- **Охват SomaFM**: все станции или топ-10/20/30 по слушателям.
- **Поиск** по названию, жанру и описанию; **сортировка кликом по колонкам** таблицы (станция, жанр/теги, трек/страна, слушатели/голоса) с направлением ↑/↓.
- **Встроенный плеер** с живой трансляцией: play/pause по клику на строку, prev/next, громкость, мьют, эквалайзер.
- **Адаптивность**: плотная таблица на десктопе, компактный список и прижатая снизу панель плеера на телефонах.
- **Доступность**: семантические кнопки, `aria-*`, фокус-контуры, `prefers-reduced-motion`.
- **Open Graph / Twitter Cards** — карточка для шаринга в мессенджерах и соцсетях.

## Быстрый старт

Сайт живёт на https://soma.guilliman.ru — можно просто открыть.

Локально — любой статический сервер, сборка не нужна:

```bash
python -m http.server 8080
# или
npx serve .
```

Страница открывается и по схеме `file://`.

## Как это работает

1. **SomaFM**: при загрузке браузер запрашивает у SomaFM XML-список каналов (`chanlist.xml`) и список плейлистов (`playlist.xml`), затем резолвит каждую `.pls`-ссылку в прямой URL потока нужного качества.
2. **radio-browser.info**: браузер обращается к публичному REST API (`all.api.radio-browser.info`) — поиск станций с фильтрами по жанру и стране, а также справочники жанров и стран. Каталог отдаёт уже разрешённые прямые ссылки. Если официальный сервер недоступен, адрес API можно заменить на своё зеркало или прокси (см. ниже).
3. По кнопке «Скачать» собирается `.m3u8` из текущего видимого списка (с учётом источника, качества/охвата, фильтров и сортировки).

Вся логика — в `assets/app.js`; конфигурация эндпоинтов, источников и качеств — в начале файла (`CHANNELS_URL`, `RB_API_DEFAULT`, `RB_API_KEY`, `SOURCES`, `KINDS`).

## Если radio-browser.info заблокирован

Весь API radio-browser сейчас живёт на **одном сервере** (`all.api.radio-browser.info` → `91.98.4.78`, Германия), поэтому в некоторых сетях — например, в России — каталог «Всё радио» недоступен, хотя сами аудиопотоки (они лежат на чужих хостах) играют. Источник SomaFM это не затрагивает.

Сайт статический, поэтому блокировку обходит **свой маленький реверс-прокси**. В репозитории лежит готовый скрипт для Cloudflare Worker:

1. Создайте Worker (`proxy/worker.js`) — через дашборд Cloudflare (вставить код и Deploy) или из CLI:

   ```bash
   cd proxy
   npx wrangler deploy
   ```

2. Скопируйте адрес вида `https://radio-browser-proxy.<account>.workers.dev`.
3. На сайте выберите источник **«Всё радио»**, раскройте **«Адрес API radio-browser — зеркало или прокси»**, вставьте адрес и нажмите «Применить».

Адрес хранится только в браузере (localStorage) и его можно передать ссылкой: `https://soma.guilliman.ru/?rb=https://ваш-прокси`. Пустое поле возвращает официальный сервер. Прокси пересылает только read-only `GET /json/*` и кэширует ответы на краю.

## Структура проекта

```
├── index.html          # разметка: генератор, таблица станций, плеер
├── assets/
│   ├── app.js          # вся логика: API, рендер, плеер, генерация плейлиста
│   ├── styles.css      # дизайн-система: токены, тёмная тема, адаптив
│   ├── favicon.svg
│   └── og-image.png    # карточка для соцсетей (1200×630)
├── proxy/
│   ├── worker.js       # Cloudflare Worker: прокси radio-browser.info (обход блокировки)
│   └── wrangler.toml   # конфиг для `npx wrangler deploy`
├── CNAME               # домен GitHub Pages
└── .nojekyll
```

## Проверки

Проект покрыт Playwright-проверками: функциональные E2E-тесты (сценарии SomaFM + один намеренный офлайн-кейс, сценарии radio-browser.info — поиск, фильтры, скачивание, переключение источника, ошибки сети), axe-аудит доступности (0 нарушений в обоих режимах), аудит раскладки (скроллы, переполнения, размеры тапов), проверки плеера, мьюта, статусной строки и `file://`-режима. Тестовый харнесс живёт отдельно от репозитория в `%TEMP%\somatest`.
