# SomaFM · генератор плейлиста

**soma.guilliman.ru** — генератор актуального M3U8-плейлиста всех радиостанций [SomaFM](https://somafm.com) прямо в браузере. Без сборки, без бэкенда, без зависимостей: открыл страницу — получил свежий плейлист с прямыми ссылками на потоки.

## Возможности

- **46 станций** SomaFM с актуальными логотипами и текущими треками (данные тянутся на лету из открытого API).
- **Три качества потока**: MP3 128, AAC ~130, AAC+ 64.
- **Прямые ссылки на потоки** — генератор сам резолвит `.pls`-ссылки в реальные URL потоков, чтобы плейлист играл без промежуточных перенаправлений.
- **Плейлист в формате M3U8**: скачивание файла или копирование в буфер обмена.
- **Охват**: все станции или топ-10/20/30 по слушателям.
- **Поиск** по названию, жанру и описанию; **сортировка кликом по колонкам** таблицы (станция, жанр, текущий трек, слушатели) с направлением ↑/↓.
- **Встроенный плеер** с живой трансляцией: play/pause по клику на строку, prev/next, громкость, мьют, эквалайзер.
- **Адаптивность**: плотная таблица на десктопе, компактный список и прижатая снизу панель плеера на телефонах.
- **Доступность**: семантические кнопки, `aria-*`, фокус-контуры, `prefers-reduced-motion`.
- **Open Graph / Twitter Cards** — карточка для шаринга в мессенджерах и соцсетях.

## Быстрый старт

Сайт живёт на https://soma.guilliman.ru — можно просто открыть.

Локально — любой статический сервер, сборка не нужна:

```bash
python -m http.server 8080
# или
npx serve .
```

Страница открывается и по схеме `file://`.

## Как это работает

1. При загрузке браузер запрашивает у SomaFM XML-список каналов (`chanlist.xml`) и список плейлистов (`playlist.xml`).
2. Сервис резолвит каждую `.pls`-ссылку в прямой URL потока нужного качества.
3. По кнопке «Скачать» собирается `.m3u8` из текущего видимого списка (с учётом качества, охвата и сортировки).

Вся логика — в `assets/app.js`; конфигурация эндпоинтов и качеств — в начале файла (`API` и `KINDS`).

## Проверки

Проект покрыт Playwright-проверками: функциональные E2E-тесты (46/46 сценариев + один намеренный офлайн-кейс), axe-аудит доступности (0 нарушений), аудит раскладки (скроллы, переполнения, размеры тапов), проверки плеера, мьюта, статусной строки и `file://`-режима. Тестовый харнесс живёт отдельно от репозитория в `%TEMP%\somatest`.
