# Guilliman's Radio · генератор плейлиста

**soma.guilliman.ru** — генератор актуального M3U8-плейлиста: все радиостанции SomaFM и десятки тысяч станций со всего мира из открытого каталога «Всё радио». Прямо в браузере, без сборки, без бэкенда, без зависимостей: открыл страницу — получил свежий плейлист с прямыми ссылками на потоки.

## Возможности

- **Три источника в одном интерфейсе**: 46 станций SomaFM, мировой каталог «Всё радио» (~60 000 станций) и вкладка «Любимое». Переключатель источника — сегментный контрол под заголовком.
- **SomaFM**: актуальные логотипы и текущие треки (данные тянутся на лету из открытого API), **три качества потока** — MP3 128, AAC ~130, AAC+ 64.
- **Всё радио**: поиск по названию, фильтры по жанру (тегу) и стране, сортировка по голосам/названию, охват топ-30/60/100/200. Показываются только станции, прошедшие последнюю проверку доступности (`hidebroken`). Текущий трек играющей станции показывается по ICY-метаданным потока — там, где станция их отдаёт (иначе выводится жанр).
- **Прямые ссылки на потоки** — SomaFM-ссылки `.pls` резолвятся в реальные URL; у каталога берётся уже разрешённый `url_resolved`, чтобы плейлист играл без промежуточных перенаправлений.
- **Карточка станции** в «Всё радио» (иконка ⓘ на строке): теги, страна/регион, язык, формат (codec, битрейт, HLS), голоса, прослушивания с трендом, статус последней проверки, сайт станции; из карточки можно слушать или скопировать ссылку на поток. Проигрывание учитывается счётчиком кликов каталога.
- **Плейлист в формате M3U8** из текущего видимого списка (с учётом источника, фильтров и сортировки): скачивание файла (`SomaFM.m3u8` / `Radio.m3u8` / `Favorites.m3u8`) или копирование в буфер обмена.
- **Любимое**: отмечайте станции звёздочкой на карточке (или кнопкой «В любимое» в карточке станции) — выбор сохраняется в браузере и собирается на отдельной вкладке в общий список из обоих источников; из него так же можно слушать и скачивать плейлист.
- **Охват SomaFM**: все станции или топ-10/20/30 по слушателям.
- **Поиск** по названию, жанру и описанию; **сортировка кликом по колонкам** таблицы (станция, жанр/теги, трек/страна, слушатели/голоса) с направлением ↑/↓.
- **Встроенный плеер** с живой трансляцией: play/pause по клику на строку, prev/next, громкость, мьют, эквалайзер.
- **Адаптивность**: плотная таблица на десктопе, компактный список и прижатая снизу панель плеера на телефонах.
- **Доступность**: семантические кнопки, `aria-*`, фокус-контуры, `prefers-reduced-motion`.
- **Open Graph / Twitter Cards** — карточка для шаринга в мессенджерах и соцсетях.

## Быстрый старт

Сайт живёт на https://soma.guilliman.ru — можно просто открыть.

Локально — любой статический сервер, сборка не нужна:

```bash
python -m http.server 8080
# или
npx serve .
```

Страница открывается и по схеме `file://`.

## Как это работает

1. **SomaFM**: при загрузке браузер запрашивает у SomaFM XML-список каналов (`chanlist.xml`) и список плейлистов (`playlist.xml`), затем резолвит каждую `.pls`-ссылку в прямой URL потока нужного качества.
2. **Всё радио**: браузер обращается к REST API каталога через встроенный прокси с автоматическим откатом на официальный сервер — поиск станций с фильтрами по жанру и стране, а также справочники жанров и стран. Каталог отдаёт уже разрешённые прямые ссылки.
3. По кнопке «Скачать» собирается `.m3u8` из текущего видимого списка (с учётом источника, качества/охвата, фильтров и сортировки).

Вся логика — в `assets/app.js`; конфигурация эндпоинтов, источников и качеств — в начале файла (`CHANNELS_URL`, `RB_API_PROXY`, `RB_API_OFFICIAL`, `SOURCES`, `KINDS`).

## Если каталог «Всё радио» недоступен

Весь API каталога сейчас живёт на **одном сервере** (`all.api.radio-browser.info` → `91.98.4.78`, Германия), поэтому в некоторых сетях — например, в России — источник «Всё радио» недоступен, хотя сами аудиопотоки (они лежат на чужих хостах) играют. Источник SomaFM это не затрагивает.

Поэтому сайт **по умолчанию ходит через встроенный реверс-прокси** (Cloudflare Worker из `proxy/worker.js`) и автоматически откатывается на официальный сервер, если прокси недоступен — настраивать ничего не нужно. Адрес прокси в исходниках хранится в закодированном виде, а сам Worker принимает запросы только с origin сайта (`https://soma.guilliman.ru` и т.п.), так что знание URL не превращает его в открытый прокси.

Свой Worker разворачивается так:

```bash
cd proxy
npx wrangler deploy
```

Он пересылает только read-only `GET /json/*`, кэширует ответы на краю (с `stale-while-revalidate`) и по умолчанию разрешён только для origin сайта (список — `DEFAULT_ALLOWED_ORIGINS` в `worker.js`, переопределяется переменной `ALLOWED_ORIGINS`). Отдельный эндпоинт `GET /icy?url=…` разово подключается к аудиопотоку и вытаскивает из его ICY-заголовков текущий трек (`StreamTitle`) — браузер этого сам не умеет из-за отсутствия CORS у потоков. Чтобы сменить адрес каталога, достаточно поправить `RB_API_PROXY` в начале `assets/app.js`.

Соединение с прокси на `*.workers.dev` иногда рвётся само по себе, поэтому сайт рассчитан на сбои: крупная выборка (топ-100/200) запрашивается **страницами по 100 станций** с дедупликацией, каждая страница повторяется при обрыве (сначала основной адрес, затем запасной), список наполняется по мере загрузки страниц, а недоставленная последняя страница не стирает уже полученные. Сам Worker тоже повторяет зависший запрос к каталогу и отвечает `504`, если апстрим не ответил, — чтобы клиент повторил попытку, а не ждал впустую.

```
├── index.html          # разметка: генератор, таблица станций, плеер
├── assets/
│   ├── app.js          # вся логика: API, рендер, плеер, генерация плейлиста
│   ├── styles.css      # дизайн-система: токены, тёмная тема, адаптив

│   └── wrangler.toml   # конфиг для `npx wrangler deploy`
├── CNAME               # домен GitHub Pages
└── .nojekyll
```

## Проверки

Проект покрыт Playwright-проверками: функциональные E2E-тесты (сценарии SomaFM + один намеренный офлайн-кейс, сценарии radio-browser.info — поиск, фильтры, скачивание, переключение источника, ошибки сети), axe-аудит доступности (0 нарушений в обоих режимах), аудит раскладки (скроллы, переполнения, размеры тапов), проверки плеера, мьюта, статусной строки и `file://`-режима. Тестовый харнесс живёт отдельно от репозитория в `%TEMP%\somatest`.
